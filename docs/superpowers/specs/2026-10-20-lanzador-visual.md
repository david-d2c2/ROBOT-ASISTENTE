# Lanzador visual

El robot debe mostrarse con una identidad reconocible tanto en el escritorio de Windows como en la aplicación. El acceso directo se llamará **Robot Asistente**, abrirá `main.py` con `pythonw.exe` sin consola y usará un icono propio coherente con el robot: carcasa plateada, pantalla oscura, dos ojos cian y ruedas.

La creación del acceso directo debe poder repetirse tras mover o reinstalar el proyecto. El script comprobará sus tres archivos necesarios antes de modificar el escritorio y conservará las rutas con espacios correctamente entrecomilladas.
